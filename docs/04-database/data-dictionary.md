# Data dictionary — Phase 2

| Table | Column | Type | Constraint |
|---|---|---|---|
| roles | id | UUID | Primary key |
| roles | name | VARCHAR(50) | Unique, not null |
| roles | description | VARCHAR(255) | Nullable |
| roles | created_at / updated_at | TIMESTAMPTZ | Not null |
| users | id | UUID | Primary key |
| users | email | VARCHAR(320) | Unique, not null |
| users | password_hash | VARCHAR(255) | Not null; never returned |
| users | full_name | VARCHAR(150) | Nullable |
| users | is_active | BOOLEAN | Not null, defaults true |
| users | email_verified | BOOLEAN | Not null, defaults false |
| users | created_at / updated_at | TIMESTAMPTZ | Not null |
| users | deleted_at | TIMESTAMPTZ | Nullable |
| user_roles | id | UUID | Primary key |
| user_roles | user_id / role_id | UUID | Foreign keys, not null |
| user_roles | assigned_at | TIMESTAMPTZ | Not null |

Entity identifiers are generated by Hibernate only for new records. The
application lifecycle callbacks populate non-null timestamps before persistence;
the database remains the schema source of truth through Flyway.
